# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep criticism about the work. Harassment of any kind isn't tolerated.

Report problems privately through GitHub's [private reporting form](https://github.com/MAKaminski/cadence/security/advisories/new), which reaches the maintainer. Reports are handled confidentially.
